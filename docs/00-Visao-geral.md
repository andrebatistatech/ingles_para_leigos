# Inglês para Leigos — visão geral

> Ponto de partida para navegar pela documentação do projeto.

## Objetivo

Oferecer a estudantes brasileiros uma plataforma de aprendizado de inglês por nível CEFR (A1–C2), com quizzes, acompanhamento de desempenho e recursos de estudo para assinantes VIP.

## Estado atual

A aplicação está implementada em Next.js 14, com Supabase para autenticação e dados. O produto já inclui quiz, dashboard, área de estudo, conta, solicitação de upgrade e administração de usuários. Veja [[05-Implementacoes|Implementações atuais]] para o inventário funcional.
